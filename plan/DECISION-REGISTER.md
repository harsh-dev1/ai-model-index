| DEC-007 | 2026-07-24 | **Epoch AI Benchmarking Hub adopted as the primary capability source**, replacing DEC-006's dropped sources | `epoch.ai/data/benchmark_data.zip`, updated the same day, **CC-BY licensed — explicitly free to redistribute with credit**. | DEC-010 | 2026-07-24 | Models whose confidence intervals overlap are displayed as **tied**, not ranked against each other | Arena publishes ±CI and Epoch publishes stderr. Ranking 3rd vs 4th across overlapping intervals is fake precision, which is the most common leaderboard failure. |
| DEC-011 | 2026-07-25 | Pillar scores are standardised to a common mean and spread before weighting | Found during Wave 3 review: the Arena boards produce systematically lower normalised scores than the benchmark pillars, so a model that *was* measured on Arena scored below an identical model that simply was not listed. Being measured must never be a penalty. |
| DEC-012 | 2026-07-25 | Benchmark normalisation clips at Tukey fences snapped to the nearest real observation, not at the 2nd/98th percentile | Percentile clipping is meaningless on the benchmarks with only a handful of entrants, where the 2nd percentile *is* the lowest value. Fences degrade gracefully as coverage shrinks. |
| DEC-013 | 2026-07-25 | Every route is written to disk as `<route>/index.html` at build time; `404.html` remains only as a fallback | The standard Pages SPA trick serves deep links with an HTTP 404 status. The page rendered fine, but shared links previewed as errors. 84 static files is a cheap price for honest status codes. |
| DEC-014 | 2026-07-25 | Display labels drop run qualifiers (`(max)`, `(unknown thinking)`) but keep version parentheticals (`(Nov 2024)`, `(Preview)`), and revert to the raw label if cleaning would make two rows identical | Sources bake the harness configuration into the model name. Stripping it is cosmetic; stripping too much would merge two separately ranked models on screen while they stay distinct in the data. |
